# living archive

A weekly record of my BFA Communication Design thesis at Parsons, plus a small portfolio of past projects.

The landing page uses the Circuit of the Americas as a timeline. Each grandstand is a week, and the car shows how far along the thesis is.

**Live site:** https://swidjajanto.github.io/swp_living_archive/

## Pages
- **Home** — the track
- **Archive** — every week, in order
- **Projects** — selected work

## Built with
Plain HTML, CSS and JavaScript. No frameworks, no build step.
